# Voice Bot in Azure – Workshop

## 🎯 Purpose of the Workshop

This workshop is designed to provide participants with practical and technical knowledge to build and deploy a voice bot in the Azure ecosystem. The bot will be accessible via a phone number and capable of conducting voice conversations based on a predefined scenario (e.g., recognizing the purpose of the call, answering questions, redirecting to a consultant, etc.).

## 🧰 Technologies Used

- **Azure Bot Service** – for hosting and managing the bot
- **Azure Communication Services (ACS)** – for handling phone calls and routing
- **Azure Cognitive Services**:
  - Speech to Text (STT)
  - Text to Speech (TTS)
  - Language Understanding (LUIS) or Azure OpenAI (GPT)
- **Application Insights** – for monitoring and diagnostics
- **Optional**: Azure Functions, external APIs, CRM integration

## ✅ Expected Outcomes

By the end of the workshop, participants will:
- Be able to independently configure a voice bot in Azure
- Have a working prototype of a voice bot that answers phone calls
- Understand integration possibilities and how to scale the solution
